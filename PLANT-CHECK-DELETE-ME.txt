Throwaway fixture. This branch exists only to prove that the `secrets` job still
fails when a secret is committed, after gitleaks-action was bumped from v2 to v3.
It is never merged and the branch is deleted once the failing run is recorded.

The value below is invented. It is not a credential, it has never been issued by
AWS, and it grants nothing. It is shaped like an AWS access key id purely so that
gitleaks' `aws-access-token` rule matches it, and it ends in FAKE so that anyone
who finds it later can tell at a glance what it is.
