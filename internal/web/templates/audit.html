Mailboxes and grants are named as they are called now, not as they were called then: an alias can be renamed, so an old row can show a name that has since moved to describing something else. What the row is actually about is the mailbox id underneath it, which never changes.

A row names what a call affected and, for outgoing mail, where it went. It never holds what was in a mailbox: no message body, and no subject or sender of a message that was read. A long list of ids or recipients is cut short, and the count beside it says how many there really were.
